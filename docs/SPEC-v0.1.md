# JASS Signal Intelligence Studio — v0.1

## Objective
A Windows desktop workspace for organizing public global information, monitoring user-defined topics, and preparing for future signal detection.

## A01 — Foundation
Electron, React, Vite, JASS identity, navigation, build scripts and safe renderer boundary.

## A02 — Local persistence
SQLite, schema version marker, event/source/topic/settings storage, validated IPC and restart persistence.

## A03 — Workspace
Situation Room, Signals, Sources, Watchlist, Timeline and Settings screens backed by local data.

## Explicit exclusions
Live data collection, advanced maps, automated alerts, AI inference and predictive claims.

## Acceptance
The application launches, all screens are navigable, records persist, local CRUD workflows operate, tests pass, production build succeeds, and packaged Windows smoke test is recorded.
